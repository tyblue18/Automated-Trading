# 2-AMP — Automated Market Predictor

2-AMP monitors financial news and SEC filings to predict near-term stock price
direction (UP / DOWN / NEUTRAL). It fetches articles from RSS feeds and the SEC
EDGAR API, runs them through a three-model voting ensemble (VADER lexicon,
FinBERT, TF-IDF + Logistic Regression), optionally refines the result with a
Gemini LLM override, and surfaces predictions through a Streamlit dashboard.
Current focus: NVDA, AMD, and TSMC.

## Quick start

**Prerequisites**

- Python 3.12 or 3.14. Python 3.12 has broader ML wheel availability; 3.14 works
  with the versions pinned in `requirements.txt` (tested) but is new enough that
  you may hit missing wheels for other packages. If installation fails, 3.12 is
  the safe fallback.
- For the RSS monitor: a Gemini API key in the environment as `GEMINI_API_KEY`.

```bash
git clone <repo-url>
cd Automated-Trading

python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS / Linux

pip install -r requirements.txt

# Train the TF-IDF model (one-time; regenerated by tfidf_lr_model.py — gitignored as *.pkl)
python src/tfidf_lr_model.py
```

**Transformers version note:** `requirements.txt` pins `transformers>=4.40,<5`.
Transformers 5.x breaks `yiyanghkust/finbert-tone` with an "Unrecognized model"
error. If you already have 5.x installed, force the downgrade:

```bash
pip uninstall -y transformers huggingface_hub tokenizers
pip install -r requirements.txt
```

## Configuration

All tunable values live in `config.yaml`. The top-level sections:

| Section | Purpose |
|---|---|
| `data` | EDGAR and GDELT pipeline settings: tickers, date ranges, HTTP limits |
| `target_company` | Company name and aliases used for RSS filtering and article search |
| `news` | Feed URLs, poll interval, dev-feed flag, retry backoff settings |
| `article_search` | Google query template for `src/article_finder.py` |
| `output` | Output file paths (e.g. `data/nvidia_articles.csv`) |
| `text_input` | UI input character cap (default 2000; conservative ceiling for FinBERT's 512-token limit) |
| `sentiment` | FinBERT model ID, VADER thresholds, batch size, TF-IDF model path |
| `logging` | Log level and optional log file |
| `performance` | Model caching flags, rate-limit delays for EDGAR and GDELT requests |

## Running the app

**Streamlit dashboard**

```bash
streamlit run app.py
```

Opens at `http://localhost:8501`. Three modes: Auto-Fetch Articles (RSS), Single
Text, and Batch Analysis. The first run downloads FinBERT (~500 MB) from
HuggingFace and caches it.

**RSS monitor — continuous**

```bash
python src/news_sentiment_analysis.py
```

Polls feeds in `config.yaml > news.feed_urls` every `check_interval_seconds`.
Filters articles by `target_company.aliases`, runs the ensemble, applies a Gemini
override, and appends results to the path in `output.articles_csv`.

**EDGAR pipeline — one-shot**

```bash
python src/pipeline_edgar.py
```

Downloads SEC filings for the tickers in `config.yaml > data.edgar`, fetches full
text, computes 3-day and 5-day return labels, writes labeled CSVs to `data/`.

**Model training and evaluation**

```bash
python src/tfidf_lr_model.py          # trains TF-IDF + LR → src/tfidf_lr_model.pkl
python src/test_ensemble_accuracy.py  # evaluates ensemble on FinancialPhraseBank
```

**Data collection scripts** (run once, in order)

```bash
python src/article_finder.py   # Google News search → forbes_search.csv
python src/article_scraper.py  # scrape article text → forbes_articles.csv
```

These scripts execute at module level — run them directly, do not import them.

and the EDGAR pipeline writes the training CSVs.

## Known limitations

See the **Known issues / future work** section in `CLAUDE.md` for a current list.
Key items: the EDGAR labeling scheme is binary (UP / DOWN, no NEUTRAL class); there
is no backtesting framework, no database layer, and no production deployment
configuration.

If `src/tfidf_lr_model.pkl` is missing (not run or deleted), the ensemble silently
degrades from 3-model to 2-model (VADER + FinBERT only). A warning is logged but
nothing is surfaced in the Streamlit UI — predictions will still appear, just from
fewer models. Run `python src/tfidf_lr_model.py` to restore the third vote.
